# AutoUp — Premium Automotive Care Products & Essentials

AutoUp offers high-performance automotive detailing shampoos, waxes, exterior cleaners, and interior conditioners with seamless quotation via WhatsApp.

## Tech Stack

- **Framework**: TanStack Start (React 19)
- **Styling**: Tailwind CSS v4 & Glassmorphism design system
- **Routing**: TanStack Router (File-based)
- **Animation**: Embla Carousel React & Tailwind CSS Animate
- **Icons**: Lucide React
- **Build Tool**: Vite & Nitro

## Local Development

```sh
npm install
npm run dev
```

The application will be running locally at `http://localhost:8081` (or next available port).

## Production Build & Tests

```sh
# Run Vitest test suite
npm run test

# Build for production
npm run build
```

## Vercel Deployment

This repository is configured for deployment on [Vercel](https://vercel.com):

1. Import this repository in your Vercel Dashboard (`https://github.com/MoeezShamshad/autoupksa.git`).
2. Build Command: `npm run build`
3. Output Directory: automatically generated by Nitro (`.output/public` / `.vercel/output`).
4. Create a Supabase project and run `supabase/migrations/202611190001_initial_schema.sql` in its SQL Editor.
5. Add these server-only environment variables in Vercel:
   - `ADMIN_EMAIL`
   - `ADMIN_PASSWORD`
   - `ADMIN_SESSION_SECRET` (at least 32 random characters)
   - `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` for persistent catalog/admin data and media uploads

Admin login and signed HTTP-only sessions use `ADMIN_EMAIL`, `ADMIN_PASSWORD`, and `ADMIN_SESSION_SECRET`; they do not contact Supabase. Sessions expire after one day, or 30 days when “Remember me” is selected. Changing the email or password requires updating the corresponding Vercel environment variable and redeploying.

Supabase remains the persistent product/admin data store. Its credentials are not required to start the application or log in, but data-management APIs and media uploads need them to preserve and update existing records. Never use a `NEXT_PUBLIC_`/`VITE_` prefix for server-only values or put them in client-side code.
